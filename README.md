# 🎮 ThuyHuong Digital 2026 — Games

Bộ sưu tập game web của hệ sinh thái ThuyHuong Digital 2026.
Tất cả game đều là HTML5 thuần (canvas 2D), **không cần cài đặt** — mở file
`index.html` bằng trình duyệt hoặc chơi trực tuyến qua GitHub Pages.
Hỗ trợ cả máy tính (bàn phím) lẫn điện thoại (cảm ứng).

### 🏴‍☠️ Bắc Hải Đảo

Game hải tặc lấy cảm hứng từ *Pirates of the Caribbean* nhưng bối cảnh thuần
Việt Nam: vịnh Bắc Bộ năm 1780. Lái thuyền buồm **cánh dơi** giữa các đảo đá
vôi Hạ Long, buôn nước mắm — lụa — trầm hương — ngọc trai qua 6 thương cảng cổ
(Vân Đồn, Cát Bà, Cô Tô…), đánh giặc **Tàu Ô**, vượt bão biển, gặp **Rồng
thiêng Hạ Long**, và hạ trùm **Hắc Giao** để xưng *Vua Bắc Hải Đảo* 👑.

Xem hướng dẫn chi tiết trong [`bac-hai-dao/README.md`](bac-hai-dao/README.md).

## Chơi trực tuyến (GitHub Pages)

Vào *Settings → Pages*, chọn nhánh `main` (thư mục `/root`) rồi lưu.
Sau vài phút, game sẽ chạy tại:
`https://thuyhuongctu.github.io/ThuyHuong_Digital-2026-Games/`
