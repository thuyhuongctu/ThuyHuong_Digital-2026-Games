# Agent skills

Kỹ năng cho phiên Claude Code làm việc trên repo này. Bảy skill dưới đây
được chọn lọc từ [mattpocock/skills](https://github.com/mattpocock/skills)
(MIT — xem `LICENSE-mattpocock-skills`):

| Skill | Dùng khi |
|---|---|
| `research` | Nghiên cứu có dẫn nguồn gốc (sử liệu cho game, tài liệu API…) |
| `grill-me` / `grilling` | "Nướng" một kế hoạch/quyết định bằng câu hỏi phản biện (vd: kế hoạch thương mại hóa) |
| `diagnosing-bugs` | Chẩn đoán bug khó theo vòng lặp giả thuyết – kiểm chứng |
| `prototype` | Dựng thử nghiệm vứt đi để trả lời một câu hỏi thiết kế trước khi làm thật |
| `wizard` | Sinh trình hướng dẫn từng bước cho việc chỉ con người làm được (vd: nộp CH Play) |
| `handoff` | Đóng gói phiên làm việc hiện tại thành tài liệu bàn giao cho phiên sau |

Các file này chỉ phục vụ quy trình phát triển — không ảnh hưởng gì đến
website/game được deploy.
